Payments

Residents would be able to pay Water/Sewer bills, Taxes, Permit Fees, and miscellaneous town fees online. The proposed flow uses Stripe Checkout — residents select a payment category, enter their account/reference number and amount due, and are redirected to a Stripe-hosted payment page. The town never handles raw card data. On completion, Stripe emails a receipt automatically and logs payment metadata (type, reference, amount, timestamp) for reconciliation.

Stripe is the payment infrastructure behind many services residents already use daily — including Shopify stores, DoorDash, Amazon, Instacart, and many others. It processes hundreds of billions of dollars per year and is trusted by governments, universities, and nonprofits worldwide. Choosing Stripe means residents are paying through the same secure, familiar system they encounter everywhere else online.

Text messaging (Twilio)

The backend for SMS notifications is fully implemented using the Twilio API, allowing staff to send text messages to residents or contacts directly from the dashboard. The function code is complete and tested — once the town establishes a Twilio account and provides the API credentials (Account SID, API Key, and sending number), this tab can be re-enabled with no code changes required.

Intended use cases include emergency notifications, meeting reminders, and utility service alerts.
